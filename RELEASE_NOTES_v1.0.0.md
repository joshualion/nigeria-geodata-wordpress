# Nigeria GeoData v1.0.0

Nigeria GeoData v1.0.0 is the first public release of Govware's WordPress geography plugin for Nigerian administrative and electoral data.

## Highlights

- one-time geography provisioning through CampaignManager.ng
- National, State/FCT, Senatorial District, Federal Constituency and LGA/Area Council scopes
- resumable batched provisioning
- additive coverage
- local Nigerian geography graph
- cascading selectors
- Data Explorer
- REST, PHP and JavaScript APIs
- native Contact Form 7 integration
- built-in GeoForms
- submissions, CSV export and email notifications
- theme-friendly frontend output
- WordPress Plugin Check clean release candidate
- CI validation across PHP 7.4, 8.1 and 8.3

## Installation

Download the attached release asset:

```text
nigeria-geodata-1.0.0.zip
```

Then install through:

```text
WordPress Admin → Plugins → Add New → Upload Plugin
```

## Provision geography

After activation:

1. Open **Nigeria GeoData** in WordPress Admin.
2. Purchase the required scope.
3. Enter the generated `NGWP-...` key.
4. Provision the dataset.
5. Use Data Explorer, shortcodes, APIs, Contact Form 7 or GeoForms.
