# WordPress.org Publication

Nigeria GeoData is prepared for submission to the WordPress.org Plugin Directory.

## Pre-submission checklist

- production ZIP installs successfully through WordPress **Upload Plugin**
- WordPress Plugin Check completes with no errors
- plugin version and `readme.txt` Stable Tag match
- GPL-compatible licence declared
- external CampaignManager.ng provisioning service documented
- production package excludes development-only files
- plugin is complete and usable at submission time

## Submission package

Submit the same production-ready ZIP used for the public GitHub v1.0.0 release:

```text
nigeria-geodata-1.0.0.zip
```

Do not submit the GitHub documentation repository's automatic source archive.

## After approval

WordPress.org will provide the plugin SVN repository. Functional plugin files belong directly in `trunk/`, release copies belong in `tags/`, and directory artwork/screenshots belong in the root-level `assets/` directory.

The public GitHub repository remains the documentation and GitHub-release distribution home; WordPress.org SVN becomes the release channel for WordPress.org installations.
