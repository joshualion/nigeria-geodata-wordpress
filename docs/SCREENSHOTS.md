# Screenshot Guide

The public repository and future WordPress.org listing should use real screenshots from a clean WordPress installation.

Recommended screenshots:

1. `dashboard-national.png` — completed National dashboard with record totals
2. `provisioning-progress.png` — overall progress plus per-dataset counters
3. `data-explorer.png` — Country → Region → State → LGA → Ward → Polling Unit
4. `coverage-expansion.png` — additive coverage or completed National state
5. `geoforms-builder.png` — GeoForms editor
6. `geoforms-frontend.png` — public form with cascading geography
7. `contact-form-7.png` — native Nigeria GeoData CF7 tags
8. `submissions.png` — GeoForms submissions dashboard

Guidelines:

- use a clean browser window
- avoid exposing keys, email addresses or sensitive information
- use PNG or WebP
- keep text readable at GitHub and WordPress.org preview sizes
- use privacy-safe demo data where submissions are visible
