# Security

Please do not publish sensitive security vulnerabilities as public GitHub issues.

For security-sensitive reports, contact Govware through the official CampaignManager.ng support/contact channel.

Include:

- affected Nigeria GeoData version
- WordPress version
- PHP version
- reproducible steps
- expected and observed behavior
- relevant logs with secrets removed

Never include provisioning keys, session tokens, passwords, API secrets, database credentials or personal data in a public report.
