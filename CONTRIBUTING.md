# Contributing

Nigeria GeoData's public repository is the official documentation and release-distribution home for the plugin.

Useful public contributions are welcome for:

- documentation improvements
- installation and hosting guidance
- tutorials and examples
- screenshots and videos
- translations
- reproducible bug reports
- compatibility findings
- feature ideas

The active plugin development source tree is maintained privately by Govware, so direct application-source pull requests are not accepted through this release repository.

## Issues

When reporting a bug, include:

- Nigeria GeoData version
- WordPress version
- PHP version
- active theme
- relevant form plugin, if applicable
- purchased geography scope
- exact error message
- reproducible steps

Do not include passwords, provisioning keys, session tokens, database credentials, email secrets or personal data.

## Documentation pull requests

Documentation-only pull requests are welcome. Keep changes focused, clear and free of sensitive data.

## Security

Do not publish security-sensitive vulnerabilities in a public issue. See [SECURITY.md](SECURITY.md).
